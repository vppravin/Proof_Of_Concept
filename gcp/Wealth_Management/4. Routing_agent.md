# Routing Agent Deployment Guide

The routing agent is special - it doesn't have an MCP server. Instead, it directly calls other Agent Engines using the Vertex AI SDK.

## Routing Agent Architecture

```
┌─────────────────────────────────────────────────────────┐
│                  Routing Agent                           │
│            (Vertex AI Agent Engine)                      │
│                                                          │
│  ┌────────────────────────────────────────────────┐    │
│  │  Agent Configuration                            │    │
│  │  - Model: gemini-2.0-flash                      │    │
│  │  - 11 FunctionTools (one per sub-agent)         │    │
│  │  - Routing logic in instructions                │    │
│  └────────────────────────────────────────────────┘    │
│                                                          │
│  ┌────────────────────────────────────────────────┐    │
│  │  tools.py                                       │    │
│  │  - call_agent_with_timeout() helper             │    │
│  │  - 11 tool functions                            │    │
│  │  - Retry logic (3 attempts)                     │    │
│  │  - SSL error handling                           │    │
│  └────────────────────────────────────────────────┘    │
└──────────────────────┬──────────────────────────────────┘
                       │ agent_engines.get() + stream_query()
                       ▼
┌─────────────────────────────────────────────────────────┐
│              Sub-Agents (11 specialized agents)           │
│  SMA | SFDC | Fund | Maps | SDI | Checking | 360 | ...  │
└─────────────────────────────────────────────────────────┘
```

## 1. Tools Implementation

### tools.py

```python
import json
import logging
import ssl
import time
from vertexai import agent_engines
from urllib3.exceptions import SSLError

# Logging
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - [ROUTING_TOOLS] - %(levelname)s - %(message)s'
)
logger = logging.getLogger(__name__)

# Timeout configuration
DEFAULT_TIMEOUT = 300  # 5 minutes

class TimeoutError(Exception):
    pass

def call_agent_with_timeout(agent_id: str, prompt: str, timeout_seconds: int = DEFAULT_TIMEOUT, max_retries: int = 3) -> str:
    """Call sub-agent with timeout and retry logic."""
    
    for attempt in range(max_retries):
        try:
            logger.info(f"Calling agent {agent_id} (attempt {attempt + 1}/{max_retries})")
            remote_agent = agent_engines.get(agent_id)
            full_response = []
            
            for event in remote_agent.stream_query(message=prompt, user_id="test-user"):
                content = event.get("content", {})
                parts = content.get("parts", [])
                for part in parts:
                    if "text" in part:
                        full_response.append(part["text"])
            
            return "".join(full_response) or "No response received"
            
        except (SSLError, ssl.SSLEOFError) as e:
            if attempt < max_retries - 1:
                wait_time = 2 ** attempt
                logger.warning(f"SSL error on attempt {attempt + 1}, retrying in {wait_time}s: {str(e)}")
                time.sleep(wait_time)
            else:
                logger.error(f"SSL error after {max_retries} attempts: {str(e)}")
                return f"Error: Connection failed after {max_retries} attempts. Please try again later."
        except Exception as e:
            logger.error(f"Error calling agent {agent_id}: {str(e)}")
            return f"Error: {str(e)}"

# Tool 1: SMA Activity
def sma_activity(prompt: str) -> str:
    """
    Sends a user prompt to the SMA agent and returns its response.
    
    Args:
        prompt (str): The user's input prompt that asks for the details on SMA activity of the lead to be processed by the agent.
    
    Returns:
        str: The response returned by the SMAAgent_mcp agent
    """
    AGENT_ENGINE_ID = "projects/146646146609/locations/us-central1/reasoningEngines/1659854639127855104"
    return call_agent_with_timeout(AGENT_ENGINE_ID, prompt)

# Tool 2: SFDC Lead Prioritization
def get_prioritized_leads(prompt: str):
    """
    Sends a user prompt to the lead prioritizer agent and returns its response.
    
    Args:
        prompt (str): The user's input prompt asking for prioritized leads.
    
    Returns:
        str: Combined response returned by the sfdc_Lead_Prioritizer agent
    """
    AGENT_ENGINE_ID = "projects/146646146609/locations/us-central1/reasoningEngines/6508120375480549376"
    return call_agent_with_timeout(AGENT_ENGINE_ID, prompt)

# ... (repeat for all 11 tools)
```

## 2. Agent Configuration

### agent.py

```python
import os
from google.adk.agents import Agent
from google.adk.tools import FunctionTool
from dotenv import load_dotenv

load_dotenv()

from routing_agent.tools import (
    get_prioritized_leads,
    task_creation,
    returns_on_fund,
    map_assistant,
    sma_activity,
    stocks_info,
    sdi_activity,
    checking_activity,
    _360_view,
    lead_comparison,
    stock_sales
)

model = "gemini-2.0-flash"

# Register all tools
tools = [
    FunctionTool(func=get_prioritized_leads),
    FunctionTool(func=task_creation),
    FunctionTool(func=returns_on_fund),
    FunctionTool(func=map_assistant),
    FunctionTool(func=sma_activity),
    FunctionTool(func=stocks_info),
    FunctionTool(func=sdi_activity),
    FunctionTool(func=checking_activity),
    FunctionTool(func=_360_view),
    FunctionTool(func=lead_comparison),
    FunctionTool(func=stock_sales)
]

# Agent
root_agent = Agent(
    model=model,
    name="Routing_agent",
    description="A smart routing agent that forwards user prompts to the appropriate specialized Vertex AI agents based on intent.",
    instruction="""
    You are a multi-agent routing assistant designed to delegate user prompts to the most appropriate downstream Vertex AI agent for processing.
    Your core responsibility is to understand the user's intent and route the prompt to the correct agent.
    You return the response exactly as received from the downstream agent, ensuring accurate, high-quality results for sales, marketing, and CRM workflows.

    ===============================
    🛠 Available Tool & Usage
    ===============================
 
    1. get_prioritized_leads()
    - Purpose: Fetches prioritized leads from Salesforce.
    
    2. task_creation()
    - Purpose: Creates a follow-up task associated with the specified lead.

    3. returns_on_fund()
    - Purpose: Retrieves investment details and return metrics for the fund invested by the specified customer.

    4. map_assistant()
    - Purpose: Fetch step-by-step driving directions between two locations

    5. sma_activity()
    - Purpose: Categorizes and sums SMA activity types.

    6. stocks_info()
    - Purpose: Use when the user wants current stock prices.

    7. sdi_activity()
    - Purpose: Activity Summary for summarizing total SDI transaction amounts by activity type

    8. checking_activity()
    - Purpose: Home Expenses to sum debit transactions excluding home goal contributions

    9. _360_view()
    - Purpose: Generates a comprehensive 360° financial summary report

    10. lead_comparison()
    - Purpose: Compares investment activities and stock behavior between two leads.

    11. stock_sales()
    - Purpose: Evaluates whether a lead sold their stocks at a good time
    
    ===============================
    📌 Routing Rules
    ===============================
    - Always call the appropriate tool based on user intent
    - Pass the complete user query to the selected tool
    - Return the tool's response directly without modification
    - If the query is ambiguous, select the most relevant tool based on keywords
    """,
    tools=tools
)
```

## 3. Deployment Script

### deploy.py

```python
import os
import logging
from dotenv import load_dotenv
from vertexai import agent_engines
import google.auth

load_dotenv()

# Logging
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - [DEPLOY_ROUTING] - %(levelname)s - %(message)s'
)
logger = logging.getLogger(__name__)

# Configuration
_, project_id = google.auth.default()
PROJECT_ID = os.getenv("GOOGLE_CLOUD_PROJECT", project_id)
LOCATION = os.getenv("GOOGLE_CLOUD_LOCATION", "us-central1")
SERVICE_ACCOUNT = os.getenv("SERVICE_ACCOUNT")

logger.info(f"Deploying routing agent to project: {PROJECT_ID}")
logger.info(f"Location: {LOCATION}")
logger.info(f"Service Account: {SERVICE_ACCOUNT}")

# Import agent
from routing_agent.agent import root_agent

try:
    logger.info("Creating routing agent engine...")
    
    agent_engine = agent_engines.create(
        agent=root_agent,
        requirements=[
            "google-cloud-aiplatform",
            "vertexai",
            "urllib3",
            "python-dotenv"
        ],
        project=PROJECT_ID,
        location=LOCATION,
        service_account=SERVICE_ACCOUNT,
        display_name="Routing Agent"
    )
    
    logger.info(f"✅ Routing agent deployed successfully!")
    logger.info(f"Agent Engine ID: {agent_engine.resource_name}")
    
    # Extract reasoning engine ID
    parts = agent_engine.resource_name.split('/')
    reasoning_engine_id = parts[-1]
    logger.info(f"Reasoning Engine ID: {reasoning_engine_id}")
    
except Exception as e:
    logger.error(f"❌ Deployment failed: {e}")
    raise
```

## 5. Prerequisites

Before deploying the routing agent, ensure:

1. **All sub-agents are deployed** (see 04-AGENT-DEPLOYMENT.md)
2. **Agent IDs are updated in tools.py**
3. **Service account has aiplatform.user role**

### Update Agent IDs

In `tools.py`, update each AGENT_ENGINE_ID:

```python
# Get agent IDs from previous deployments
# Format: projects/{project_number}/locations/{location}/reasoningEngines/{id}

# Example:
AGENT_ENGINE_ID = "projects/146646146609/locations/us-central1/reasoningEngines/1659854639127855104"
```

```bash
PROJECT_ID="gbu-demo-playground"

  --member="serviceAccount:${SERVICE_ACCOUNT}" \
```

## 7. Routing Agent Workflow

```
User Query
    ↓
Routing Agent (analyzes intent)
    ↓
Selects appropriate tool
    ↓
call_agent_with_timeout()
    ↓
agent_engines.get(sub_agent_id)
    ↓
remote_agent.stream_query(message=prompt)
    ↓
Sub-Agent processes via MCP server
    ↓
Response streamed back
    ↓
Routing agent returns response to user
```
