# MCP Server Deployment Guide

This guide covers deploying MCP (Model Context Protocol) servers to Cloud Run. The process is the same for all agents.

## MCP Server Architecture

```
┌─────────────────────────────────────────────────────────┐
│                    MCP Server                            │
│                  (Cloud Run Service)                     │
│                                                          │
│  ┌────────────────────────────────────────────────┐    │
│  │  FastMCP Application                            │    │
│  │  - SSE Transport (/sse endpoint)                │    │
│  │  - Tool Definitions (@mcp.tool decorators)      │    │
│  │  - Business Logic                               │    │
│  └────────────────────────────────────────────────┘    │
│                                                          │
│  ┌────────────────────────────────────────────────┐    │
│  │  Starlette Web Server                           │    │
│  │  - Health check endpoints                       │    │
│  │  - SSE connection handling                      │    │
│  └────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

## File Structure

Each MCP-based agent requires these files:

```
agent_name/
├── mcp_tool_<agent>.py      # MCP server with tools
├── Dockerfile                # Container definition
├── requirements.txt          # Python dependencies
└── .env                      # Environment variables
```

## 1. MCP Server Code Template

### mcp_tool_<agent>.py

```python
import os
import logging
from typing import Optional
from fastmcp import FastMCP
from starlette.applications import Starlette
from starlette.routing import Route, Mount
from starlette.requests import Request
from starlette.responses import JSONResponse
from mcp.server.sse import SseServerTransport
import uvicorn
from google.cloud import bigquery

# Logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

# Initialize clients
PROJECT_ID = os.getenv("GOOGLE_CLOUD_PROJECT", "gbu-demo-playground")
client = bigquery.Client(project=PROJECT_ID)

# Create FastMCP instance
mcp = FastMCP("Agent Name MCP Server")

# Define tools
@mcp.tool
def tool_name(param: str) -> dict:
    """Tool description for the agent."""
    logger.info(f"Tool invoked: tool_name with param: {param}")
    
    try:
        # Business logic here
        query = f"SELECT * FROM `{PROJECT_ID}.Wealth_Management.Table` WHERE condition"
        results = client.query(query).result()
        
        # Process results
        output = "Processed data"
        
        logger.info("Tool completed successfully")
        return {"result": output}
    except Exception as e:
        logger.error(f"Error in tool: {e}")
        return {"error": str(e)}

# SSE Transport
sse = SseServerTransport("/sse/messages")

async def handle_sse(request: Request):
    """Handle SSE connections from Agent Engine."""
    logger.info(f"SSE connection request from {request.client.host}")
    _server = mcp._mcp_server
    try:
        async with sse.connect_sse(
            request.scope,
            request.receive,
            request._send,
        ) as (reader, writer):
            logger.info("SSE connection established")
            await _server.run(reader, writer, _server.create_initialization_options())
            logger.info("MCP server session completed")
    except Exception as e:
        logger.error(f"Error in SSE handler: {e}")
        raise

async def health_check(request: Request):
    """Health check for Cloud Run."""
    return JSONResponse({"status": "healthy", "service": "Agent MCP Server"})

# Starlette app
app = Starlette(
    debug=False,
    routes=[
        Route("/", endpoint=health_check),
        Route("/health", endpoint=health_check),
        Route("/sse", endpoint=handle_sse),
        Mount("/sse/", app=sse.handle_post_message),
    ],
)

if __name__ == "__main__":
    port = int(os.environ.get("PORT", 8080))
    logger.info(f"Starting MCP Server on port {port}")
    uvicorn.run(app, host="0.0.0.0", port=port, log_level="info")
```

## 2. Dockerfile Template

```dockerfile
FROM python:3.10-slim

WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y \
    gcc \
    git \
    && rm -rf /var/lib/apt/lists/*

# Copy requirements first for layer caching
COPY requirements.txt .

# Install Python dependencies
RUN pip install --no-cache-dir -r requirements.txt

# Copy the rest of the app
COPY . .

# Expose port (Cloud Run default)
EXPOSE 8080

# Start the FastMCP server using Uvicorn
# Replace 'mcp_tool_<agent>' with actual filename (e.g., mcp_tool_sma)
CMD uvicorn mcp_tool_<agent>:app --host 0.0.0.0 --port ${PORT:-8080}
```

**Note**: Replace `<agent>` with the actual agent name in the CMD line:
- For SMA agent: `CMD uvicorn mcp_tool_sma:app --host 0.0.0.0 --port ${PORT:-8080}`
- For Lead agent: `CMD uvicorn mcp_tool_lead:app --host 0.0.0.0 --port ${PORT:-8080}`
- For Checking agent: `CMD uvicorn mcp_tool_checking:app --host 0.0.0.0 --port ${PORT:-8080}`

## 6. Deployment Steps

### Step-by-Step Process

```bash
# 1. Navigate to agent directory
cd /home/ec2-user/.cache/gcp-agentspace/agents/<agent_name>

# 2. Verify files exist
ls -la
# Should see: mcp_tool_*.py, Dockerfile, requirements.txt, .env

# 3. Build and push MCP server image to Artifact Registry
gcloud builds submit --region=us-central1 \
  --tag us-central1-docker.pkg.dev/gbu-demo-playground/cloud-run-source-deploy/mcp-<agent-name>:latest

# 4. Deploy MCP server to Cloud Run (Change to public)
gcloud run deploy mcp-<agent-name> \
  --image=us-central1-docker.pkg.dev/gbu-demo-playground/cloud-run-source-deploy/mcp-<agent-name>:latest \
  --platform=managed \
  --region=us-central1 \
  --allow-unauthenticated

# 5. Get MCP server URL
MCP_URL=$(gcloud run services describe mcp-<agent-name> \
  --region=us-central1 --format='value(status.url)')
echo "MCP Server URL: ${MCP_URL}"
echo "SSE Endpoint: ${MCP_URL}/sse"

# 6. Update agent.py with MCP server URL
# Edit agent.py and replace MCP_SERVER_URL with: ${MCP_URL}/sse

# 7. Deploy Vertex AI Agent (Verify Agent_Deployement)
python deploy.py

# 8. Test MCP server health
curl ${MCP_URL}/health
```

# GCS File Server - Setup Guide

The gcs_show folder contains a separate Flask microservice that serves PDF reports stored in Google Cloud Storage. This is used by the 360 Agent to provide downloadable/viewable PDF reports to users.

## USAGE :

Stocka_Agent--> Provides the image view trend of the stocks
360_Agent--> Provides the PDF of the lead

## ARCHITECHTURE :

360 Agent → Generates PDF Report → Uploads to GCS → Returns URL
                         ↓
User clicks URL → gcs_show Service → Fetches from GCS → Serves PDF


## Overview
Flask server that serves files (images, PDFs, etc.) from Google Cloud Storage bucket.

## Prerequisites
- Python 3.10+
- Google Cloud Platform account
- GCS bucket with your files
- GCP service account with Storage Object Viewer permissions


## Deployment Configuration

### Environment Variables

```bash
# Set these variables for deployment
export PROJECT_ID="gbu-demo-playground"
export PROJECT_NUMBER="146646146609"
export REGION="us-central1"
export FILE_NAME="<server-file>"  # e.g., "stock-chart", "360-report"
export SERVICE_NAME="gcs-${FILE_NAME}-${PROJECT_NUMBER}"
export REPOSITORY="cloud-run-source-deploy"
export IMAGE_NAME="us-central1-docker.pkg.dev/${PROJECT_ID}/${REPOSITORY}/${SERVICE_NAME}:latest"
export SERVICE_ACCOUNT="${PROJECT_NUMBER}-compute@developer.gserviceaccount.com"
```

## Deployment Steps

### Step-by-Step Process

```bash
# 1. Navigate to agent directory
cd gcp-agentspace/agents/<FILE_NAME>

# 2. Verify files exist
ls -la
# Should see: main.py, Dockerfile, requirements.txt

# 3. Build and push server image to Artifact Registry
gcloud builds submit --region=us-central1 \
  --tag us-central1-docker.pkg.dev/gbu-demo-playground/cloud-run-source-deploy/gcs-<FILE_NAME>:latest

# 4. Deploy to Cloud Run
gcloud run deploy gcs-<FILE_NAME> \
  --image us-central1-docker.pkg.dev/gbu-demo-playground/cloud-run-source-deploy/gcs-<FILE_NAME>:latest \
  --region us-central1 \
  --service-account ${SERVICE_ACCOUNT} \
  --allow-unauthenticated

# 5. Get server URL
SERVER_URL=$(gcloud run services describe gcs-<FILE_NAME> \
  --region=us-central1 --format='value(status.url)')
echo "Server URL: ${SERVER_URL}"
echo "Health Check: ${SERVER_URL}/"
echo "File Endpoint: ${SERVER_URL}/server_file/<filename>"
```
## API Endpoints

- `GET /` - Health check
- `GET /chart/<filename>` - Serve file from GCS (supports images, PDFs, etc.)
