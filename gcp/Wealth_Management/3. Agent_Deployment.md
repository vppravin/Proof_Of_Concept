# Agent Engine Deployment Guide

This guide covers deploying agents to Vertex AI Agent Engine. Each agent connects to its MCP server deployed on Cloud Run.

## Agent Architecture

```
┌─────────────────────────────────────────────────────────┐
│              Vertex AI Agent Engine                      │
│                                                          │
│  ┌────────────────────────────────────────────────┐    │
│  │  Agent Configuration                            │    │
│  │  - Model: gemini-2.0-flash                      │    │
│  │  - Name & Description                           │    │
│  │  - Instructions                                 │    │
│  └────────────────────────────────────────────────┘    │
│                                                          │
│  ┌────────────────────────────────────────────────┐    │
│  │  MCPToolset                                     │    │
│  │  - Connection to MCP Server (SSE)               │    │
│  │  - Timeout: 30s per attempt                     │    │
│  │  - Retries: 3 attempts                          │    │
│  └────────────────────────────────────────────────┘    │
└──────────────────────┬──────────────────────────────────┘
                       │ HTTPS/SSE
                       ▼
┌─────────────────────────────────────────────────────────┐
│              MCP Server (Cloud Run)                      │
└─────────────────────────────────────────────────────────┘
```

## File Structure

Each agent requires these files:

```
agents/
agent_name/
├── __init__.py             # Python package marker
├── agent.py                # Agent configuration
├── deploy.py               # Deployment script
└── .env                    # Environment variables
```

## 1. Agent Code Template

### agent.py (MCP-based Agent)

```python
from google.adk.agents import Agent
from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset, SseConnectionParams
import os
import logging
import time
import google.auth
from dotenv import load_dotenv

load_dotenv()

# Logging
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - [AGENT_NAME] - %(levelname)s - %(message)s'
)
logger = logging.getLogger(__name__)

logger.info("Initializing Agent...")

# Authentication
_, project_id = google.auth.default()
logger.info(f"Authenticated with project: {project_id}")

os.environ.setdefault("GOOGLE_CLOUD_PROJECT", project_id)
os.environ.setdefault("GOOGLE_CLOUD_LOCATION", "global")
os.environ.setdefault("GOOGLE_GENAI_USE_VERTEXAI", "True")

# Configuration
model = os.getenv("model", "gemini-2.0-flash")
mcp_server_url = os.getenv("MCP_SERVER_URL")

logger.info(f"Using model: {model}")
logger.info(f"Connecting to MCP Server: {mcp_server_url}")

# MCP Toolset with retry logic
MAX_RETRIES = 3
RETRY_DELAY = 2
TIMEOUT_PER_ATTEMPT = 30

toolset = None
for attempt in range(1, MAX_RETRIES + 1):
    try:
        logger.info(f"MCP connection attempt {attempt}/{MAX_RETRIES}...")
        toolset = MCPToolset(
            connection_params=SseConnectionParams(
                url=mcp_server_url,
                timeout=TIMEOUT_PER_ATTEMPT,
                headers={"Connection": "keep-alive"}
            ),
            errlog=None
        )
        logger.info(f"MCP Toolset initialized successfully on attempt {attempt}")
        break
    except Exception as e:
        logger.warning(f"Attempt {attempt} failed: {e}")
        if attempt < MAX_RETRIES:
            logger.info(f"Retrying in {RETRY_DELAY} seconds...")
            time.sleep(RETRY_DELAY)
        else:
            logger.error(f"Failed to initialize MCP Toolset after {MAX_RETRIES} attempts")
            raise

# Create Agent
root_agent = Agent(
    model=model,
    name="Agent_Name",
    description="Agent description - what this agent does",
    instruction="""
    Detailed instructions for the agent on how to use its tools
    and respond to user queries.
    
    When user asks X, call tool Y with parameter Z.
    Format responses as...
    """,
    tools=[toolset]
)

logger.info("Agent created successfully")
```

## 2. Deployment Script Template

### deploy.py

```python
import os
import sys
import vertexai
from vertexai import agent_engines
from vertexai.preview.reasoning_engines import AdkApp
from dotenv import load_dotenv

# Add parent directory to path for imports
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import agent as <agent_module>

load_dotenv()

PROJECT = "gbu-demo-playground"
LOCATION = "us-central1"
BUCKET_URI = "gs://wm_agent"

vertexai.init(project=PROJECT, location=LOCATION, staging_bucket=BUCKET_URI)

print("Wrapping agent for deployment...")
adk_app = AdkApp(agent=<agent_module>.root_agent, enable_tracing=True)

print("Deploying to Vertex AI Reasoning Engine...")
remote_app = agent_engines.create(
    adk_app,
    display_name=<agent_module>.root_agent.name,
    description="<Agent Description>",
    requirements=[
        "cloudpickle",
        "google-cloud-aiplatform",
        "pydantic",
        "google-adk==1.18.0",
        "google-genai==1.47.0",
        "python-dotenv==1.2.1",
        "mcp",
        "httpx-sse",
    ],
    extra_packages=["./<agent_folder>/"],
    env_vars={
        "GOOGLE_CLOUD_AGENT_ENGINE_ENABLE_TELEMETRY": "true",
        "OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT": "true",
        "MCP_SERVER_URL": "<MCP_SERVER_URL>",
    },
)

print(f"\n✅ Successfully deployed!")
print(f"Reasoning Engine: {remote_app.resource_name}")
print(f"Display Name: {<agent_module>.root_agent.name}")
```

**Replace placeholders:**
- `<agent_module>` - Agent module name (e.g., `sma_agent`, `sold_stocks_agent`)
- `<Agent Description>` - Description of what the agent does
- `<agent_folder>` - Agent folder name (e.g., `SMA_agent`, `sold_stocks`)
- `<MCP_SERVER_URL>` - Your MCP server URL with `/sse` endpoint

## 4. Deployment Steps

### Step-by-Step Process

```bash
# 1. Ensure MCP server is deployed first
# See -MCP-DEPLOYMENT.md

# 2. Navigate to agent directory
cd /home/ec2-user/.cache/gcp-agentspace/agents/

# 3. Update .env with MCP server URL
# Get URL from MCP deployment
SERVICE_URL=$(gcloud run services describe mcp-<agent>-146646146609 \
  --region=us-central1 --format='value(status.url)')
echo "MCP_SERVER_URL=${SERVICE_URL}/sse" >> .env

# 4. Verify files
ls -la
# Should see: __init__.py, agent.py, deploy.py, .env

# 5. Set project
gcloud config set project gbu-demo-playground

# 6. Authenticate
gcloud auth application-default login

# 7. Deploy agent
python -m <agentname>.deploy

# 8. Note the Agent Engine ID from output
# Example: projects/146646146609/locations/us-central1/reasoningEngines/1659854639127855104
```

## 7. Update Agent

When you make changes to agent.py:

```bash
# 1. Make changes to agent.py

# 2. Redeploy
python -m <agentname>.deploy

# Note: This creates a new version, old version remains accessible
```
