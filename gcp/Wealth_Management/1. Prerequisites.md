# Prerequisites and GCP Setup

## 1. GCP Project Setup

### Create/Select Project
```bash
# Set project
gcloud config set project gbu-demo-playground

# Verify
gcloud config get-value project
```

### Enable Required APIs
```bash
# Enable all required APIs
gcloud services enable \
  aiplatform.googleapis.com \
  run.googleapis.com \
  artifactregistry.googleapis.com \
  bigquery.googleapis.com \
  storage.googleapis.com \
  cloudbuild.googleapis.com \
  iam.googleapis.com \
  compute.googleapis.com
```

## 2. Service Account Setup

### Default Compute Service Account
The system uses the default compute service account:
```
146646146609-compute@developer.gserviceaccount.com
```

### Required IAM Roles

Grant the following roles to the service account:

```bash
PROJECT_ID="gbu-demo-playground"
PROJECT_NUMBER="146646146609"
SERVICE_ACCOUNT="${PROJECT_NUMBER}-compute@developer.gserviceaccount.com"

# Vertex AI User (for Agent Engine)
gcloud projects add-iam-policy-binding ${PROJECT_ID} \
  --member="serviceAccount:${SERVICE_ACCOUNT}" \
  --role="roles/aiplatform.user"

# BigQuery Data Viewer (read data)
gcloud projects add-iam-policy-binding ${PROJECT_ID} \
  --member="serviceAccount:${SERVICE_ACCOUNT}" \
  --role="roles/bigquery.dataViewer"

# BigQuery Job User (run queries)
gcloud projects add-iam-policy-binding ${PROJECT_ID} \
  --member="serviceAccount:${SERVICE_ACCOUNT}" \
  --role="roles/bigquery.jobUser"

# Storage Object Viewer (read from buckets)
gcloud projects add-iam-policy-binding ${PROJECT_ID} \
  --member="serviceAccount:${SERVICE_ACCOUNT}" \
  --role="roles/storage.objectViewer"

# Storage Object Creator (write to buckets)
gcloud projects add-iam-policy-binding ${PROJECT_ID} \
  --member="serviceAccount:${SERVICE_ACCOUNT}" \
  --role="roles/storage.objectCreator"

# Cloud Run Invoker (invoke Cloud Run services)
gcloud projects add-iam-policy-binding ${PROJECT_ID} \
  --member="serviceAccount:${SERVICE_ACCOUNT}" \
  --role="roles/run.invoker"

# Artifact Registry Reader (pull Docker images)
gcloud projects add-iam-policy-binding ${PROJECT_ID} \
  --member="serviceAccount:${SERVICE_ACCOUNT}" \
  --role="roles/artifactregistry.reader"
```

### Verify IAM Roles
```bash
gcloud projects get-iam-policy ${PROJECT_ID} \
  --flatten="bindings[].members" \
  --filter="bindings.members:serviceAccount:${SERVICE_ACCOUNT}" \
  --format="table(bindings.role)"
```

## 3. Artifact Registry Setup

### Create Docker Repository
```bash
# Create repository for MCP server images
gcloud artifacts repositories create mcp-servers \
  --repository-format=docker \
  --location=us-central1 \
  --description="MCP server Docker images for wealth management agents"

# Verify
gcloud artifacts repositories list --location=us-central1
```

### Configure Docker Authentication
```bash
# Configure Docker to use gcloud for authentication
gcloud auth configure-docker us-central1-docker.pkg.dev
```

## 4. Cloud Run Configuration

### Set Default Region
```bash
gcloud config set run/region us-central1
```

### Verify Cloud Run Access
```bash
gcloud run services list --region=us-central1
```

## 5. Verify Setup

Run this verification script:

```bash
#!/bin/bash
echo "=== GCP Setup Verification ==="

echo "1. Project:"
gcloud config get-value project

echo "2. APIs Enabled:"
gcloud services list --enabled | grep -E "(aiplatform|run|artifactregistry|bigquery|storage)"

echo "3. Service Account:"
gcloud iam service-accounts describe ${SERVICE_ACCOUNT}

echo "4. Artifact Registry:"
gcloud artifacts repositories list --location=us-central1

echo "5. Docker Auth:"
cat ~/.docker/config.json | grep us-central1-docker.pkg.dev

echo "=== Setup Complete ==="
```

## 6. External API Setup

### Salesforce API
1. Login to Salesforce
2. Go to Setup → Apps → App Manager
3. Create Connected App
4. Get Consumer Key and Secret
5. Generate Security Token

### Google Maps API
1. Go to Google Cloud Console
2. Enable Maps JavaScript API, Places API, Directions API
3. Create API Key
4. Restrict key to your project
